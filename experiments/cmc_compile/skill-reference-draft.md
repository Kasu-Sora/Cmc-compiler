适用：从 C* 迁移包含操作语义、编译保持性与具体缓冲区关系的编译器契约。不要把本案例的 18 项不变量或具体目录结构规定为其他项目必须采用的设计。

## 三层证明衔接

先检查源契约是否量化源程序执行、目标对象解码和目标机终止。若有这些结论，单独迁移代码长度或输出数组内容不足以关闭顶层后置条件；也不能用任意谓词、未证明的 preservation 参数或调用方证书代替它。

本例依次具备真实 Tower C−/TVM 执行语义、逐步模拟与原观察保持性、最后实际 C 实现资源证明。纯数学阶段按依赖批次编译，逐条审计 Print Assumptions，并用独立 coqchk 检查冻结的源码／产物。单批通过只记录该批，顶层 C 通过前不登记全案例成功。

允许以更强的内部不变量组织归纳，但最终公开保持性和成功桥必须保持原前提与输入／输出／退出状态结论。记录原不变量的可达状态定理与原任意状态 step 定理的区别，不能从“根定理成立”推断每个源 helper 都逐名迁移。

## HOL 总查询与 helper 接入

保留 HOL 空列表／非法索引的解释参数，在合法域证明与已有 lookup 一致。此例将 `cm_source_lookup_policy` 的函数解释投影到旧 `cm_lookup_policy`，并用真实 codegen 条件实例化 helper 的模型参数。参数化含义与业务输入前提分开，不通过加强 C Requires 排除原有分支。

已验证 helper 的 With/Require/Ensure 可直接接入；记录来源并核对实际文本及实例化。callee 的保证只覆盖已验证内容，不能额外加入“编译保持性”等未承诺结论。

## 缓冲区与局部资源

原资源在零容量时允许空所有权／空指针时，使用保留该条件的数组包装，不能一律要求非空指针。最终状态区分精确 opcode、immediate、data 前缀和未写尾部。

resolved emitter 是逻辑视图；物理 CALL 回填后才能直接使用最终 opcode/immediate 数组内容。局部 emitter 所有权及 `globals`、`strings` 等仍在作用域中的局部绑定要留给返回时回收。中间 Assert 记录状态转换，不把缺失前提挪进入口契约。

具体局部字段的类型化地址可定向实例化 `eval_addr`。本例无界 `rewrite !eval_addr` 导致证明检查持续重写，限定到所需 emitter 地址后通过调试；出现类似停顿时先定位单步 tactic，而非扩大语义展开或给契约增加前提。

## 计量与信任边界

纯语义／保持性库、案例新增空间包装／公共引理、顶层 annotation/manual proof 分账。复用库的新增成本为零，复制的 helper 契约仍计接入标注。保留失败 symexec、同一 annotation attempt 内的修复、报告格式修复和 proof 检查次数；不同错误不能合并成同一种证明重试。

源的同名声明切片或保守词法依赖切片不是完整最小闭包，也不是历史人工耗时；不能与全部目标 proof 行数直接作效率比率。C* inline proof 与 QCP Assert/VC 会改变成本所在类别，至少同时报告 specification、annotation、case proof 和新增公共支持。

QCP proof_auto 的可信自动 Admitted 单列；手工 VC 和新增公共数学的实际内核证明另列。本例数学定理的假设审计闭合，并不表示 QCP 整个框架或自动结果没有信任假设。

## 重放与范围

实际 C 验证遵循仓库 AGENTS.md 的 controller 角色边界。前置依赖缺口解决后恢复原 annotation owner，保留原失败报告；不伪造缺失 VC 或修改 controller 状态。工具恢复修改单独留补丁、检查证据，不计入逻辑 proof。

保证范围是成功终止执行的输入／输出／退出状态保持，加上具体 C 缓冲区和容量分支契约。不额外声称发散保持、双向等价、所有示例/导出推论的逐一迁移，或独立 TVM C 解释器实现验证。
